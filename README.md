# EV_Market_overview
🚗 EV Vehicle Analytics Dashboard

📌 Project Title

EV Vehicle Analytics Dashboard

📖 Short Description

An interactive Electric Vehicle (EV) Analytics Dashboard developed to analyze and visualize EV market trends, vehicle performance, pricing, battery capacity, range, and manufacturer insights. This project helps users explore key patterns in the EV industry through dynamic charts, KPIs, and data-driven insights.

🛠 Tech Stack

- Power BI – Data visualization and dashboard creation
- Excel / CSV – Data source and preprocessing
- SQL – Data querying and transformation
- DAX – Calculated measures and KPIs
- Power Query – Data cleaning and transformation

✨ Features

- 📊 Interactive dashboard with filters and slicers
- 🚘 EV brand and model analysis
- 🔋 Battery capacity and driving range comparison
- 💰 Price analysis across different EV segments
- ⚡ Performance metrics visualization
- 🌍 Market trend and manufacturer insights
- 📈 KPI cards for quick decision-making
- 🎨 User-friendly and responsive dashboard design

🎯 Project Objective

To provide meaningful insights into the Electric Vehicle market and help users understand trends, pricing, and performance using data analytics and visualization techniques.
